# jsdsm

把 DSM 透明加密环境中的文件读取为明文，并保存到本地目录的命令行工具。

npm 包：`@pxsemic/jsdsm`；安装后命令名为 `jsdsm`。

```bash
npx @pxsemic/jsdsm "<文件路径>"             # 保存到源文件所在目录
npx @pxsemic/jsdsm "<文件路径>" "<输出目录>"   # 保存到指定目录
```

> 这不是密码学意义上的“解密”：工具不读取密钥，也不做解密运算。能否读到明文取决于
> 当前运行环境；写入由系统提供的组件完成，避免内容被重新加密或写入被拦截。

## 要求

- Node.js >= 18。
- 系统可用的写入组件。Windows 通常已自带；macOS / Linux 需按系统说明安装。
- 工具会自动探测写入组件；探测不到时可用 `--writer-path` 或环境变量
  `JSDSM_WRITER_PATH` 指定。

## 安装与运行

无需安装，直接：

```bash
npx @pxsemic/jsdsm "D:\资料\报告 2026.txt"
```

或全局安装：

```bash
npm install -g @pxsemic/jsdsm
jsdsm "D:\资料\报告 2026.txt" "D:\导出目录"
```

## 参数

```text
jsdsm <文件路径> [输出目录]

选项:
  -o, --out <目录>         输出目录（等同于第二个位置参数）
      --writer-path <路径> 指定写入组件路径（通常无需设置）
      --timeout <秒>       写入超时，默认 600 秒；0 表示不超时
  -h, --help               显示帮助
  -v, --version            显示版本
```

- 第一个位置参数：源文件路径，必填。
- 第二个位置参数或 `-o/--out`：输出目录，可选；**默认是源文件所在目录**。
- 输出目录不存在时自动递归创建。
- 文件名以 `-` 开头时，用 `--` 分隔：`jsdsm -- "-weird.txt"`。

## 进度与退出码

运行过程中会显示读取、写入与校验进度，例如：

```text
正在读取：D:\资料\报告 2026.txt
正在写入：D:\导出目录
已处理 12.3 MB
正在校验写入结果…
```

最终文件路径与字节数单独输出，便于脚本读取。

| 退出码 | 含义                                   |
| ------ | -------------------------------------- |
| 0      | 成功                                   |
| 1      | 运行失败（读取、写入、校验、重命名等） |
| 2      | 用法错误                               |

## 风险与限制

- **默认写回源文件目录**：如果该目录受 DSM 透明加密管控，写出的明文可能被重新加密
  或写入被拦截。建议显式指定受控范围之外的输出目录。
- **不做内容校验**：工具只保证“读到的字节”与“写出的字节”一致，不判断读到的
  是否真的是明文。若运行环境未返回明文，输出内容也会是密文。
- **单个文件**：不支持目录批量、标准输入输出或断点续传。
- **Windows 路径**：含空格或中文时用双引号包住；反斜杠无需转义。旧 `cmd.exe`
  建议先执行 `chcp 65001` 以正常显示中文。
- **平台**：正式使用环境以 Windows 为主；macOS/Linux 需要安装对应的写入组件，
  主要用于开发调试。
